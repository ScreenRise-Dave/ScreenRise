# ScreenRise Website Architecture

## Purpose

The ScreenRise website promotes the organisation, showcases productions,
explains the mission and provides routes for participation, partnership
and support.

## Hosting Architecture

Developer
    ↓

GitHub Repository
    ↓

Cloudflare Pages
    ↓

Public Website

## Technology Stack

| Component | Technology |
|-----------|------------|
| Hosting | Cloudflare Pages |
| Source Control | GitHub |
| Website | HTML |
| Styling | CSS |
| Behaviour | JavaScript |
| Images | Local image files |
| Videos | YouTube embeds |

## Site Structure

Home
├─ About
├─ Films
├─ Partnerships
├─ Support Us
└─ Contact

## Page Purpose

### Home

Primary audience:
- Emerging talent

Purpose:
- Excite visitors
- Explain value proposition

Key message:
- Make Films. Build Credits. Launch Careers.

### About

Primary audience:
- General public

Purpose:
- Explain mission
- Explain CIC status

Key message:
- Film production is our mechanism.
- Creating opportunity is our purpose.

### Films

Primary audience:
- Participants
- Supporters
- Partners

Purpose:
- Showcase productions
- Demonstrate impact

### Partnerships

Primary audience:
- Universities
- Colleges
- Schools
- Community organisations

Purpose:
- Explain collaboration opportunities

### Support Us

Primary audience:
- Sponsors
- Funders
- Donors

Purpose:
- Explain how support creates opportunities

### Contact

Primary audience:
- Everyone

Purpose:
- Provide a call to action

## Design Principles

- Mobile first
- Minimal JavaScript
- Consistent visual identity
- Film Cards used for productions
- YouTube used for video hosting
- Posters stored locally

## Future Enhancements

- Production galleries
- Sponsor logos
- Participant success stories
